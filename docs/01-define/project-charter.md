# Project Charter — Proactive Dispute Status Updates

## Business case
Status-chasing calls inflate contact-centre cost and erode trust. Closing the communication “black hole” between back-end investigation and customer channels should cut repeat calls and lift CSAT without changing investigation SLAs.

## Success criteria
| Metric | Baseline (illustrative) | Target |
|--------|-------------------------|--------|
| Avg follow-up calls / dispute | 1.4 | ≤ 0.98 (−30%) |
| % disputes with ≥1 status-chase call | TBD in Measure | −30% relative |
| CSAT (dispute journey) | Track monthly | Stable or ↑ |
| Notification coverage at milestones | Near 0 proactive | ≥ 95% of eligible events |
