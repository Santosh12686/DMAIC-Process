# Control Plan

## Monthly monitoring
| KPI | Cadence | Owner | Action if off-track |
|-----|---------|-------|---------------------|
| Follow-up calls / dispute | Monthly | Dispute Ops | Review failed/missing events |
| CSAT dispute journey | Monthly | CX | Template / timing tune |
| Notify success rate | Weekly | Digital / AI | Fix publisher gaps |
| Info-needed response time | Monthly | Ops | Clarify customer asks |

## Standardization
Automated event-driven triggers are **SOP** for all in-scope dispute categories (see [`sop-event-triggers.md`](sop-event-triggers.md)).

## Audit checklist (sample)
- [ ] Event catalogue still maps 1:1 to live publishers  
- [ ] Templates approved and versioned  
- [ ] Quiet hours / channel preference respected  
- [ ] Baseline vs current chart reviewed in ops forum
